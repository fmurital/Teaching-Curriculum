# STAT 8320: Multivariate Statistics

Spring 2027, Section W01. Mondays only, 5:45 PM to 8:30 PM. KSU Online.
January 11 to May 3, 2027.

Kennesaw State University, College of Computing and Software
Engineering, School of Data Science and Analytics.
Instructor: Faruk Muritala.

**Catalog description (verified against the current KSU catalog, listed
there as "STAT 8320: Applied Multivariate Data Analysis"):** survey
course in statistical analysis techniques; through a combination of
textbook and real-world data sets, students gain hands-on experience
with data reduction techniques (Principal Components Analysis, Common
Factor Analysis), ANOVA/MANOVA/MANCOVA, Cluster Analysis, Survival
Analysis, and Decision Trees. **Prerequisite:** STAT 7220 and STAT 7210.

## Notes on the format

This is a graduate course meeting once a week for close to three hours,
delivered online. That shape drives the design: a single long synchronous
session cannot be lecture throughout, so each session is planned as
concept, demonstration, hands-on work, and discussion, with the hands-on
portion done live rather than assigned afterward.
