# Teaching-Curriculum

A centralized academic curriculum and learning ecosystem containing course materials, lecture slides, labs, assignments, projects, datasets, teaching resources, and educational repositories across Data Science, Statistics, Machine Learning, Sports Analytics, Quality Engineering, SPC, Business Analytics, and related fields.

Built and maintained under Faruk Muritala's ACLOS (Academic Curriculum & Learning Operating System). Each course below is its own fully self-contained folder: it does not depend on any other course folder for textbooks, datasets, assignments, labs, videos, or references.

## Courses

- [Sports Analytics (Undergraduate)](Sports-Analytics-Undergraduate/) -- first flagship course, undergraduate version
- [Sports Analytics (Graduate)](Sports-Analytics-Graduate/) -- first flagship course, graduate version

More courses (Data Science, Applied Statistics, Machine Learning, Data Mining, Statistical Process Control, Quality Engineering, Business Analytics, Research Methods, Graduate Seminars, PhD Special Topics) will be added here over time, each as its own top-level, self-contained folder.
