# DATA 3230 Major Assignment Submission Template

This is the standard submission format for every major assignment this semester (three total, roughly every three to four modules). Copy this file (or the matching section of it) for each assignment, keep the structure exactly as given, and fill in only the blanks. Do not change the field labels, add extra narrative outside the labeled fields, or reorder the sections. The point of this format is that every student's submission looks the same, so keep yours plain.

## How to fill this out

1. Fill in the header block once at the top of your file.
2. For each task, there are up to three fields: **Value**, **Output / Image**, and **Interpretation**. A given task only has the fields it actually needs; if a task has no Interpretation field, do not add one.
3. **Value** is a single number, name, or short phrase, exactly as asked. No units unless the task says to include them. No sentence.
4. **Output / Image** is your R output pasted in or a chart exported as an image. For a chart, export it as a PNG named exactly `q<task number>_output.png` (for example `q2_output.png`) and reference it with the image line already in this template; do not rename the placeholder file name format. For console/table output, paste the plain text between the code fences already provided; do not retype or reformat it by hand.
5. **Interpretation** is capped at three sentences. Say what the number or chart means, not what you did to get it. If your answer runs longer than three sentences, cut it down before submitting.
6. Submit this file together with your `.R` script (or `.qmd`/`.Rmd`) and every image file it references, in a single folder or zipped archive named `LastName_FirstName_Assignment<number>`.
