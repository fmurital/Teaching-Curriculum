# Module 02: Problems and Principles in Communicating Data

**Overview:** This module steps back from code for a moment to ask why some visualizations communicate instantly while others confuse or mislead. It covers the five-step research process, a simple model of communication (Shannon and Weaver, 1949), three types of communication problems, and six practical principles for communicating data well. Every real example, including the deliberately bad ones, is built from the same `ames_housing.csv` dataset introduced in Module 1, the course's one running lecture dataset.
