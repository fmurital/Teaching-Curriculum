# Module 4 Class Session Plan (3 Hours)

This session plan follows the course's standard three-segment structure, with a 10-minute break after each of the first two segments. The slide deck itself is organized into five labeled segments (A through E); segment A runs together with segment B before the first break, since it is short on its own, and segments D and E run together before the second break for the same reason.

## Segment 1: A Communication Goal, and Bar Charts for Amounts (about 70 minutes)

- Concept Introduction (10 min): Introduce "communicating amounts" as the first of three core communication goals this course names, connecting back to Module 3's grammar.
- Concept Introduction (5 min): Frame this module's running real question: average sale price across the 23 qualifying Ames neighborhoods.
- Demonstration (15 min): Live-run the rough default bar chart, then walk through the four real changes needed to finish it (sort, annotate, flip, finish labels).
- Demonstration (10 min): Live-run the finished bar chart together, pointing out the dollar annotation on each bar.
- Discussion (10 min): Ask the class which neighborhood they expected to be highest before the chart confirmed NoRidge, and why.
- Video (3 min): Play the bar-chart-design video from `Videos/Module_04_Videos.md`.
- Reflection (5 min): One-minute written response: name one specific thing the rough version of this chart was still missing before it was ready for an audience.

## Break (10 minutes)

## Segment 2: Dot Charts (about 40 minutes)

- Concept Introduction (10 min): Introduce the Cleveland dot plot as a second, equally valid way to encode the same real amount.
- Demonstration (10 min): Live-run the dot-plot version of the exact same 23 real neighborhood averages.
- Discussion (10 min): Ask the class, looking at the bar chart and the dot plot side by side, which one they personally find easier to scan, and why; make clear there is no single correct answer.
- Video (3 min): Play the dot-plot video from `Videos/Module_04_Videos.md`.
- Reflection (5 min): Write one sentence: name one real situation where a dot plot would be the better choice over a bar chart.

## Break (10 minutes)

## Segment 3: Annotation and Ordering (about 70 minutes)

- Concept Introduction (10 min): Introduce highlighting as a second kind of annotation, using the real NoRidge example.
- Demonstration (10 min): Live-run the highlighted bar chart together.
- Discussion (5 min): Ask the class why highlighting every category a different color would defeat the purpose.
- Concept Introduction (10 min): Introduce the building-type average-quality question, and the three ordering choices (alphabetical, ascending, descending).
- Demonstration (15 min): Live-run all three ordering versions side by side, asking students to say out loud which one actually answers the real question before revealing the discussion slide.
- Interactive Activity (15 min): In-Class VizLab. In pairs, students build the average-overall_qual-by-building-type chart from Lab 4, choose their own ordering and one highlight, and share their choices with the class.
- Wrap-Up (5 min): Preview Module 5 (legends, colors, fonts, and axes), and confirm Lab 4, the practice questions, and the Module 4 quiz are due before then.

## Materials Needed

Projector or screen for the live R demonstrations, and students' own laptops with R, RStudio, and `ames_housing.csv` already set up from Modules 1 through 3.
