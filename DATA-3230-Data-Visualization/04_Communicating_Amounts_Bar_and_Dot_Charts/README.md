# Module 04: Communicating Amounts: Bar and Dot Charts

**Overview:** This module specializes the grammar from Module 3 toward the first of three core communication goals this course names: "how much" or "how many." It takes one real question, average sale price across 23 Ames neighborhoods, from a rough default bar chart to a sorted, annotated, finished one, redraws the same real numbers as a Cleveland dot plot, highlights a single category directly on the chart, and uses a second real question (average sale price by building type) to show why the order categories appear in is a real communication choice, not a cosmetic one. Every example runs on `ames_housing.csv`, the course's one running lecture dataset.
