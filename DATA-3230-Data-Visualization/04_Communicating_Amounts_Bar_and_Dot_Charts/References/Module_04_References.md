# Module 4 References

## Required Reading

Course Student Notes (this module), covering communicating amounts as a core goal, bar charts, Cleveland dot plots, annotation, and ordering.

## Primary Sources

Cleveland, W. S. (1985). *The Elements of Graphing Data*. Wadsworth Advanced Books and Software. (The original source for the dot plot named after Cleveland, used in this module's Segment C.)

Jones, B. (2014). *Communicating Data with Tableau: Designing, Developing, and Delivering Data Visualizations* (1st ed.). O'Reilly Media. ISBN 978-1449372026. (The general communication-goals framing this course follows, introduced in Module 2.)

## Package Documentation

Wickham, H., Navarro, D., & Pedersen, T. L. (2024). *ggplot2: Elegant Graphics for Data Analysis* (3rd ed.). Springer. Available online at https://ggplot2-book.org/.

## Dataset Source

De Cock, D. (2011). Ames, Iowa: Alternative to the Boston Housing Data as an End of Semester Regression Project. *Journal of Statistics Education*, 19(3).
