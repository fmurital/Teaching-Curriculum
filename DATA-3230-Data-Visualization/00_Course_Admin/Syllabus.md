## Course Description

This course introduces students to the field of data visualization. The course covers basic design and evaluation principles to prepare and analyze large datasets, and standard visualization techniques for different types of data using modern data visualization software. The course prepares students to communicate clearly, efficiently, and in a visually compelling manner to a variety of audiences.

## Course Learning Outcomes

Upon completion of this course, students should be able to:

1. List and compare the different tools and technologies used for data visualization.
2. Describe the variety of data visualization techniques and their appropriateness for different data types and visualization goals.
3. Explain the principles of designing effective data visualizations.
4. Design and implement useful data visualizations for data understanding and communication.
5. Use existing tools to render data visualizations.

## How This Course Runs

Each class session pairs a short concept segment with hands-on work at your keyboard. A given module's material is not tied to a single class meeting: some modules run long and continue into the next session, and I will tell you in class exactly where we are picking back up. Plan around the module, not the calendar date.

Every visualization you build in this course, in a lecture example, a practice question, or a graded assignment, answers three questions before it is judged on anything else:

1. Who is the audience?
2. What should they take away?
3. What should they do about it?

If a chart cannot answer those three questions, it is not finished, no matter how clean the code behind it is.

**Practice questions.** Each module includes a short, ungraded set of practice questions, built to take about 10 to 20 minutes, meant as review and reinforcement rather than a second assignment. These are also the main pool I draw from when building midterm and final project material, so working through them across the term is the best preparation for both.

## Policy on the Use of Artificial Intelligence

AI use is allowed, but not required. You are welcome to use AI tools in this course, including for writing R code. You should know that these tools regularly produce code that runs and still draws the wrong chart, and that they will happily invent a function argument that does not exist. You are responsible for any inaccurate, misleading, or faulty content you submit, regardless of where it came from. If you use an AI tool for any part of an assignment, project, or quiz, credit its contribution in your submission: what you used it for, and what you changed or verified yourself. Submitting AI-assisted work without that acknowledgment is treated as academic dishonesty under the KSU Code of Academic Integrity, the same as any other uncredited source.
