# Module 01: Getting Started with R and RStudio

**Overview:** This module gets everyone's R and RStudio environment running together, covers the basics of navigating the IDE and writing R code, and takes a first, honest look at the two real datasets this course runs on all semester: a real Ames, Iowa home-sale dataset and a real secondary-school student performance dataset. Every later module builds on this same toolchain and these same datasets.
