# Module 03: The Grammar of Graphics / Introduction to ggplot2

**Overview:** This module introduces `ggplot2`'s layered grammar of graphics: every chart is built from data, an aesthetic mapping, and a geom, optionally extended with a scale and a theme. It opens with one deliberate exception to the course's one-dataset rule, a single bare-minimum example on the built-in `mpg` dataset, before returning to our own `ames_housing.csv` for every other example: a first scatterplot taken from rough to finished, four real aesthetic mappings (color, size, shape, and the mapped-versus-set distinction), a bar chart taken from rough to finished, and themes and scales treated as their own independent grammar layers.
