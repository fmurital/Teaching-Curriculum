# Module 02: Pace, Ratings, and the Four Factors

**Maps to:** Chapter 2 (part A), Data and Basic Statistical Analyses of the course textbook (Zuccolotto, P., & Manisera, M. (2020). *Basketball Data Science: With Applications in R*. Chapman & Hall/CRC Data Science Series, CRC Press.)

**Throughline(s):** Game analysis

## Overview

Team pace, offensive and defensive ratings, and Dean Oliver's Four Factors framework (effective field goal percentage, turnover rate, offensive rebound rate, free throw rate) as implemented in `BasketballAnalyzeR`, computed on real NBA team-season data bundled with the package.
