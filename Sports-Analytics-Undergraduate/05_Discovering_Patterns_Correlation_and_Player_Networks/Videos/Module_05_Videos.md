# Module 5 Videos

- **"Correlation - The Basic Idea Explained"** (YouTube:
  https://www.youtube.com/watch?v=qC9_mohleao). A concept-explainer
  video walking through what a correlation coefficient actually means
  in plain language, giving students a visual, non-basketball
  introduction to correlation before we compute our own real 7-by-7
  matrix from 2017-18 NBA per-minute rates. Exact channel name and
  runtime were not confirmed at the time this was added; verify both
  before assigning, and swap in an alternative if the video has since
  been removed or re-titled.

- **"What Is A Hockey Assist In College Basketball?"** (YouTube,
  College Basketball Insiders channel:
  https://www.youtube.com/watch?v=m0fzhcJTSdc). A concept-explainer on
  the "hockey assist," the pass that sets up the pass that leads to a
  score, useful for showing students that an assist network is really
  a chain of real, connected decisions on the floor, not just a single
  box score number. Exact runtime was not confirmed at the time this
  was added; verify before assigning.

- **"The 2017 Warriors Had Such ELITE Ball Movement"** (YouTube:
  https://www.youtube.com/watch?v=5xav-WV0tWo). Real game footage of
  the Golden State Warriors' 2017-18 ball movement, the same team and
  season this module's assist-network data is built around, useful
  for showing students what a distributed, multi-playmaker offense
  actually looks like on the court before comparing it to Houston's
  and Cleveland's real assist networks. Exact channel name and runtime
  were not confirmed at the time this was added; verify both before
  assigning.

- **"How to Create Correlation Plots in R"** (YouTube:
  https://www.youtube.com/watch?v=X12BoYpIjyw). A coding-syntax
  tutorial video on building and reading correlation plots in R,
  useful as a supplementary walkthrough alongside this module's own
  live `corranalysis()` demonstration in
  `Coding_Exercise/module5_correlation_networks.R`. Exact channel name
  and runtime were not confirmed at the time this was added; verify
  before assigning.
