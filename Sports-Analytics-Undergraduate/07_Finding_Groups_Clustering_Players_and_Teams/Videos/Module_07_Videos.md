# Module 7 Videos

- **"What Is Hierarchical Clustering and How Does It Work?"** (also
  listed as "StatQuest: Hierarchical Clustering") (YouTube, StatQuest
  with Josh Starmer channel:
  https://www.youtube.com/watch?v=7xHsRkOdVwo). A concept-explainer
  showing exactly how a dendrogram builds itself, step by step, by
  repeatedly merging the two closest points, the same real mechanism
  behind `hclustering()`. Channel confirmed via an independent video
  summary source; exact runtime was not independently confirmed at
  the time this was added, so verify before assigning.

- **"Identifying NBA Player Archetypes Using KMeans Clustering - Part
  One"** (YouTube, Nick's Niche channel:
  https://www.youtube.com/watch?v=-FjW5E0U8gY). A real coding-syntax
  tutorial walking through k-means clustering applied to real NBA
  player data, useful alongside this module's own live-coding
  segments for students who want a second walkthrough of the same
  kind of workflow. Channel confirmed by fetching the tutorial's own
  companion article, which embeds this exact video; exact runtime was
  not independently confirmed at the time this was added, so verify
  before assigning.

- **"Rudy Gobert - Rugged Rim Protector 16/17 (Block Party)"**
  (YouTube, search result title as shown:
  https://www.youtube.com/watch?v=3hc5uitfYjk). Real game footage of
  Rudy Gobert's shot-blocking and rim protection from the era
  immediately surrounding this module's real 2017-18 data, useful for
  showing students what real Cluster 3 ("rim-protecting bigs") looks
  like in action before looking at the real block and rebound rate
  numbers behind that cluster. Confirmed to exist via web search;
  channel name and exact runtime were not independently confirmed at
  the time this was added, so verify before assigning.

- **"The Evolution of Positionless Basketball"** (YouTube, search
  result title as shown: https://www.youtube.com/watch?v=TdKHVK9EQ9Q).
  A concept-explainer on versatile, do-everything players who do not
  fit a single traditional position, useful for grounding real
  Cluster 6 (Kevin Durant, Draymond Green, Giannis Antetokounmpo,
  Anthony Davis) in real basketball context before looking at that
  cluster's real, highly varied statistical profile (CHI = 0.95).
  Confirmed to exist via web search; channel name and exact runtime
  were not independently confirmed at the time this was added, so
  verify before assigning.
