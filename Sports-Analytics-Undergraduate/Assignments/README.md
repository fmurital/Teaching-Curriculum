# Assignments

Three assignments run across the semester, each pulling together a few modules' worth of work:

- **Assignment 1** -- Modules 1-3 (getting oriented in `BasketballAnalyzeR`, pace and ratings, the Four Factors, and comparison plots).
- **Assignment 2** -- Modules 4-6 (shot charts, correlation and player networks, event density and shooting under pressure).
- **Assignment 3** -- Modules 7-9 (clustering, regression and surface dynamics, and the applied toolkit).

Each module also has a short quiz in its own folder. The midterm project and the final project (which also serves as the course's final exam) are separate -- see [Midterm Project](../Midterm_Project/) and [Final Project / Exam](../Final_Project_Exam/).
