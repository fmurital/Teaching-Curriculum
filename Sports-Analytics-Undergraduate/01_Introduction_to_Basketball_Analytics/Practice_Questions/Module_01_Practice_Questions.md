# Module 1 Practice Questions

These are for your own practice and are not submitted or graded. Solutions are discussed in class.

1. In your own words, what is the difference between sports analytics as a general field and the specific methods this course covers?
2. Name one real historical development in sports analytics discussed in Module 1 and explain briefly why it mattered.
3. What does each row of the `Pbox` dataset represent? What does each row of the `Tbox` dataset represent?
4. Why does `Pbox` have far more rows than `Tbox`, given that both come from the same NBA season?
5. Suppose a classmate tells you "the team with the most points per game is definitely the best team in the league." Using what you learned in Module 1, explain what is missing from that claim.
6. Employers hiring for sports analytics roles look for a specific mix of skills. Name three of them, as discussed in Module 1, and explain which one you personally feel least confident in right now.
7. What are the five throughlines this course returns to across the semester? Pick one and write a one-sentence question about a real team or player that fits under it.
8. Write the R code you would use to compute each team's average points allowed per game if you had a dataset called `Obox` with columns `PTS` and `GP`, following the same pattern used for `Tbox` in Lab 1.
