# Module 01: Introduction to Basketball Analytics

**Maps to:** Chapter 1, Introduction of the course textbook (Zuccolotto, P., & Manisera, M. (2020). *Basketball Data Science: With Applications in R*. Chapman & Hall/CRC Data Science Series, CRC Press.)

## Overview

What sports analytics is and why teams and researchers use it, a short history of the field, and the basic analytics workflow this course follows all semester: get data, describe it honestly, model it carefully, and communicate the result. The module also gets everyone's R/RStudio environment running together with the `BasketballAnalyzeR` package (Zuccolotto & Manisera's companion package to the textbook) and its bundled real NBA data, since every later module builds on this same toolchain.
