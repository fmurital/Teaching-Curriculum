# Module 09: The BasketballAnalyzeR Package: Applied Toolkit

**Maps to:** Chapter 6, The R Package BasketballAnalyzeR of the course textbook (Zuccolotto, P., & Manisera, M. (2020). *Basketball Data Science: With Applications in R*. Chapman & Hall/CRC Data Science Series, CRC Press.)

## Overview

Pulling the semester's methods (Four Factors, shot charts, clustering, regression) together through `BasketballAnalyzeR` as a single applied toolkit. Students build an end-to-end analysis pipeline on a team or player of their choosing.
