# Course Administration

- [Syllabus](Syllabus.md) -- instructor info, learning outcomes, required materials, grading, and policies.
- [Course Schedule](Schedule.md) -- session-by-session calendar.
- [Textbook](Textbook.md) -- required text and companion data/code.

Term-specific logistics (exact course number, section, meeting time, and room) are set by the instructor before each offering and filled into the Syllabus and Schedule above once confirmed.

The full textbook PDF is kept in the private repo (`00_Course_Admin/Textbook/`) rather than here, since its redistribution rights in a public repo have not been confirmed. Enrolled students should access the text through the usual channel (library reserve, purchase, or department-provided access).
