# Final Project / Exam

This folder holds the course's final project, which also serves as the course's final exam -- there is no separate final exam. The project applies the semester's methods (Modules 1-9) to a team or player of the student's choosing using `BasketballAnalyzeR`, with a written report and a presentation. Students who want to go further can extend the instructor's own Quality Monitoring / injury-risk research (Module 10) as an advanced option.
