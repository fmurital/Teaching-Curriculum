# Datasets

This course does not redistribute copies of datasets. Where a module uses data bundled with an R package (for example, the NBA 2017-2018 data shipped with `BasketballAnalyzeR`: `Pbox`, `Tbox`, `Obox`, `Tadd`, `PbP.BDB`), that module's README says so and the data is loaded via the package itself (`data(Tbox)`, etc.), not copied here. Any dataset specific to a module and not available through a package will be documented in that module's own `References/` folder along with its source and license.
