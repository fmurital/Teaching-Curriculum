# Textbooks

## Required

Zuccolotto, P., & Manisera, M. (2020). *Basketball Data Science: With Applications in R*. Chapman & Hall/CRC Data Science Series, CRC Press. ISBN 978-1-138-60081-2 (print) / 978-0-429-89426-8 (ebook).

Chapter map: Part I -- Ch.1 Introduction, Ch.2 Data and Basic Statistical Analyses (pace, ratings, Four Factors, comparison plots, variability/inequality, shot charts). Part II -- Ch.3 Discovering Patterns (correlation, networks, event density, shooting under pressure), Ch.4 Finding Groups (k-means, hierarchical clustering), Ch.5 Modeling Relationships (regression, surface area dynamics). Part III -- Ch.6 The R Package BasketballAnalyzeR.

Companion R package: `BasketballAnalyzeR` (CRAN), which bundles real NBA 2017-2018 data used throughout the course (`Pbox`, `Tbox`, `Obox`, `Tadd`, `PbP.BDB`).
