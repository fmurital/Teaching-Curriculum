# Case Studies (Sports Analytics)

Each case study below is described here with a citation back to the original. When a lab or lecture uses the underlying method, the code is rebuilt for teaching purposes in the relevant module folder rather than copied in directly.

## Case Study 1: MLB Pitcher Reinjury Monitoring (Quality Monitoring module)

Muritala, F., Brown, A. R., & Haller, A. (2026). "A Quality Monitoring Approach to Evaluating Reinjury Likelihood to Major League Baseball Pitchers." *Research in Sports Medicine*. https://doi.org/10.1080/15438627.2026.2632610

Original repository (research, not course material): github.com/fmurital/A-Quality-Monitoring-Approach-to-Evaluating-Re-Injury-Likelihood-to-MLB-Pitchers

Constructs a control-charting / process-capability (Cp) technique on game-by-game WHIP data from injured MLB pitchers to evaluate reinjury likelihood. This is the founding case study for Module 07.

## Case Study 2: NBA Reinjury Extension

NBA-side extension of the same quality-monitoring methodology (Tention, Muritala, Frankel & Brown, manuscript under review at *Basketball Studies*). Computes league-average performance metrics (PIE, Usage Rate, BPM, Net Rating) and pre/post-injury comparisons.

## Case Study 3: Braves Batter Monitoring (exploratory)

Original repository (research/exploratory, not course material): github.com/fmurital/Braves-Baseball-Monitoring

Exploratory EWMA-style monitoring statistic applied to Atlanta Braves batter data, plus a batter heatmap visualization. Working research code rather than teaching-ready material; if used, it will be rewritten (parameterized paths, cleaned data-entry step, teaching-oriented comments) rather than copied as-is.
