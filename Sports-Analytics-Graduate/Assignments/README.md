# Assignments

Three assignments run across the semester, each pulling together a few modules' worth of work:

- **Assignment 1** -- Modules 1-3 (lineup splits and combinations, clutch and situational splits).
- **Assignment 2** -- Modules 4-6 (season segments, spatial dynamics and tracking data, athletic motion and pose estimation).
- **Assignment 3** -- Modules 7-9 (ball trajectories and object detection, performance maps and court segmentation, machine-learning models for scoring probability).

Each module also has a short quiz in its own folder, for practicing that module's material. The midterm project and the final project (which also serves as the course's final exam) are separate -- see [Midterm Project](../Midterm_Project/) and [Final Project / Exam](../Final_Project_Exam/).
