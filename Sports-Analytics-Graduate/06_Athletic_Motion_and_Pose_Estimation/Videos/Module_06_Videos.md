# Module 6 Videos

Graduate-level note: this course's video budget goes entirely to real game footage and real
concept explainers, not coding-syntax tutorials (see the playbook's graduate video policy).
Live in-class coding still happens; it is simply not paired with a tutorial video here.

- **"But what is a neural network? | Deep learning chapter 1"** (YouTube, 3Blue1Brown channel:
  https://www.youtube.com/watch?v=aircAruvnKk). A real, widely used concept-explainer building
  the plain-language intuition for how a neural network turns raw input into a learned
  judgment, the same underlying mechanism (extended to convolutional layers) behind MoveNet's
  real 17-keypoint pose output. Confirmed to exist via web search and independently well known;
  exact runtime was not re-confirmed at the time this was added, so verify before assigning.

- **"Kyrie Irving Sick Crossovers & Handles in Slow-Motion"** (YouTube, search result title as
  shown: https://www.youtube.com/watch?v=LZSlFyyCkhk). Real game footage of crossover
  ball-handling in slow motion, useful for grounding section 6.5.1's "Crossover" pose analysis
  in what the actual movement looks like before discussing what a pose-estimation system would
  need to measure to quantify it. Confirmed to exist via web search; channel name and exact
  runtime were not independently confirmed at the time this was added, so verify before
  assigning.

- **"Stephen Curry Shooting Form Slow Motion 2024-25 (1080_HD)"** (YouTube, search result title
  as shown: https://www.youtube.com/watch?v=azm2YIMUcVM). Real game/practice footage of jump
  shot release mechanics in slow motion, useful for grounding section 6.5.2's "Shot" pose
  analysis and this module's real free-throw-mechanics discussion in what the actual release
  looks like. Confirmed to exist via web search; channel name and exact runtime were not
  independently confirmed at the time this was added, so verify before assigning.
