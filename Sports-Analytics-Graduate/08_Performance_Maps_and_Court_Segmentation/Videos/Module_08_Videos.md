# Module 8 Videos

Graduate-level note: this course's video budget goes entirely to real
game footage and real concept explainers, not coding-syntax tutorials
(see the playbook's graduate video policy). Live in-class coding still
happens; it is simply not paired with a tutorial video here.

- **"Decision and Classification Trees, Clearly Explained!!!"**
  (YouTube, StatQuest: https://www.youtube.com/watch?v=_L39rN6gz7Y).
  A concept-explainer on how a classification tree like CART actually
  splits data, the same real method behind this module's two scoring
  probability maps. Confirmed to exist via web search; exact runtime
  was not independently confirmed at the time this was added, so
  verify before assigning.

- **"Golden State Warriors' Beautiful Ball Movement"** (YouTube:
  https://www.youtube.com/watch?v=DHPD1HZg8-I). Real game footage
  showing how the shots behind this module's real Golden State shot
  chart actually get created on the floor. Confirmed to exist via web
  search; channel name and exact runtime were not independently
  confirmed at the time this was added, so verify before assigning.

- **"3-Point Revolution: Part One"** (YouTube:
  https://www.youtube.com/watch?v=T-p_5P9UISs). A real concept piece
  on the shift toward three-point shooting, directly grounding this
  module's real finding that three-pointers carry higher expected
  points per shot than mid-range attempts despite a lower real field
  goal percentage. Confirmed to exist via web search; channel name
  and exact runtime were not independently confirmed at the time this
  was added, so verify before assigning.
