# Final Project / Exam

This folder holds the course's final project, which also serves as the course's final exam -- there is no separate final exam. The project applies the semester's methods (Modules 1-9) to a team, player, or dataset of the student's choosing, with a written report and a presentation. Students who want to go further can extend the injury-risk signature module (Module 10) into a larger independent or PhD-level project, connecting a real workload or motion-tracking indicator to a specific, cited model from the course's own research track.
