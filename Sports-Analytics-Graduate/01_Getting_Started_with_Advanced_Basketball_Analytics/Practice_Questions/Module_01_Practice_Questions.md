# Module 01 Practice Questions (Ungraded)

Use these to check your own understanding before the graded quiz. They are not collected.

1. What problem does `pacman::p_load()` solve that a plain `library()` call does not?

2. `dplyr` and base R both define a function called `filter()`. What goes wrong if you load `dplyr` without resolving that conflict, and how does `conflicted::conflict_prefer()` fix it?

3. In the top-scorers pipeline, why does the code `filter(MIN >= 500)` before computing `PPG`, rather than after? What would change in the result if you filtered after instead?

4. The 2017-18 GSW assist network showed Draymond Green with more total assists than Kevin Durant or Stephen Curry. Does that make Green the most important offensive player on the team? What would you need to know beyond total assists to answer that question?

5. Klay Thompson had roughly 83% of his made shots assisted; Kevin Durant had roughly 54%. Name one basketball explanation for that gap that has nothing to do with either player's skill level.

6. This course draws on real journal articles in addition to the textbook. Name one of the three papers introduced this session and, in one sentence, what question it addresses.

7. What is the deliverable, by the end of the course, for a student pursuing the PhD-level injury-detection track?
