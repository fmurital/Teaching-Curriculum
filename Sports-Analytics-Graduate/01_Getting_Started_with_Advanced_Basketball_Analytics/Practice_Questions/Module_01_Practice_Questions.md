2. What actually goes wrong if you load `dplyr` without resolving its
   `filter()` naming conflict with base R, and how does
   `conflicted::conflict_prefer()` fix it?

a. Nothing goes wrong; R automatically resolves the conflict on its own
b. Whichever package loaded last silently wins, so code can run without error while using the wrong `filter()`; `conflict_prefer()` makes the choice explicit
c. R refuses to run any code at all until the conflict is resolved manually
d. `conflict_prefer()` permanently deletes the losing function from R

3. In the top-scorers pipeline built in this module, why does the code

a. Order does not matter; filtering before or after produces an identical top-scorers list

c. PPG cannot be computed at all until the minutes filter is applied
d. Filtering before computing PPG removes every player who is not on Golden State

5. In the 2017-18 Golden State Warriors assist network built in this
   module, Draymond Green recorded 509 total assists, more than Kevin
   Durant (366) or Stephen Curry (309). Does that make Green the team's
   most important offensive player?

a. Yes, total assists is the definitive measure of offensive importance
b. Not necessarily; total assists rewards volume and playing time, so assist rate, the quality of shots created, and each player's own scoring role also matter

d. Yes, but only because Green also led the team in scoring that season
